## 📖 О проекте

**DDoS Attack Simulator** - это образовательная платформа для изучения механизмов распределенных атак типа "отказ в обслуживании" (DDoS) и методов защиты от них. Проект создан исключительно в учебных и исследовательских целях для специалистов в области кибербезопасности.

### ⚠️ Важное предупреждение

**Данный симулятор предназначен ТОЛЬКО для образовательных целей.** 
- Проведение реальных DDoS атак является уголовно наказуемым преступлением
- Используйте знания исключительно для защиты собственной инфраструктуры
- Не используйте симулятор для проведения реальных атак

## 🚀 Возможности

### 🎯 Типы моделируемых атак
- **HTTP/HTTPS Flood** - атаки на веб-приложения
- **SYN Flood** - эксплуатация TCP handshake
- **UDP Flood** - объемные атаки на сетевую инфраструктуру  
- **ICMP Flood** - ping-запросы для перегрузки канала
- **DNS Amplification** - атаки с усилением через DNS
- **Slowloris** - медленные HTTP соединения
- **Смешанные атаки** - комбинации различных техник

### 🛡️ Система защиты
- **Аппаратные профили** - 50+ конфигураций оборудования
- **Cloudflare защита** - моделирование CDN защиты
- **WAF (Web Application Firewall)** - фильтрация HTTP трафика
- **Rate Limiting** - ограничение запросов
- **Гео-фильтрация** - блокировка по регионам
- **IP репутация** - системы черных списков
- **Поведенческий анализ** - обнаружение аномалий
- **CAPTCHA системы** - вызовы для проверки

### 📊 Аналитика и визуализация
- **Реалтайм метрики** - PPS, нагрузка, эффективность защиты
- **Фрактальный анализ** - параметр Хёрста для трафика
- **Выявление узких мест** - CPU, память, сетевые интерфейсы
- **Финансовый ущерб** - моделирование бизнес-последствий
- **Детальная статистика** - пиковые значения, длительность, эффективность
